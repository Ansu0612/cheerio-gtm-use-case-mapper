# Cheerio GTM Use-Case Mapper

An evidence-first GTM research system for identifying and prioritizing potential Cheerio AI workflow opportunities across customer-facing industries.

## Why I Built This

A GTM Engineer should not start with:

> "Which companies use WhatsApp?"

The better question is:

> "Which companies have customer workflows where better communication and orchestration could influence a measurable business outcome?"

This project turns public company research into a repeatable GTM opportunity-mapping workflow.

---

## MVP Scope

The initial research universe contained **50 companies** across four industries.

After geographic and data validation:

**50 → 41 retained companies**

For the MVP, I randomly selected:

**3 companies × 4 industries = 12 deeply researched companies**

| Industry | Companies Researched |
|---|---:|
| D2C | 3 |
| BFSI | 3 |
| Real Estate | 3 |
| Healthcare | 3 |
| **Total** | **12** |

The goal was to test the methodology across different customer journeys rather than build a statistically representative ICP.
